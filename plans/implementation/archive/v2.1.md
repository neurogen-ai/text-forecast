# Plan 2.1 — Implementation plan (scout + oracle refined)

Refines `plans/releases/2.1.md` tasks T0–T4 against actual code. Each step fits one
context window and lands as one commit.

## Settled decisions

**CLI surface: Option A (repeatable ordered `--op` flags).** Typer preserves
the order of repeated options natively, so flag position gives execution order
for free. Option B needs a custom multi-command parser for zero user benefit
today; the only consumer is the user's own shell history, and 2.x promises no
back-compat. Revisit only if op-specific flags collide across op types.

**LengthTrim semantics (pending T0 confirmation):** correct the two flipped
comparisons and simplify. Drop a row when `len < min_chars` (hard minimum,
replaces the current `max(mean - 3σ, min_len)` fold); when `max_sigma` is set,
compute mean/std once per column per partition and drop rows with
`len > mean + max_sigma * std`. No lower statistical bound anymore. This
intentionally changes level-3 behaviour beyond the sign fix; the
old-level→flags mapping table in docs absorbs it. If T0 shows the inverted
comparisons were intentional, stop and re-specify before T1.

**Filter fate:** `main()` only reads `exclude_quality` and `exclude_lang`.
The `tails` and `remove` lists are dead code; delete them along with the
duplicates ("copyright" twice; Chinese particle block repeated under "Common
single char words") when dissolving `Filter` into `EXCLUDE_QUALITY` /
`EXCLUDE_LANG` module constants.

## Task sequence

### T0 — Regression test pinning length-trim intent
- **Goal:** failing test that states intended trim behaviour before any refactor.
- **Files:** `tests/test_clean.py` (new).
- **Changes:** build a small LazyFrame with a known length distribution
  (e.g. lengths 5–60); call `clean.main(lf, col="text", min_len=10, level=3)`
  and assert the *intended* (non-inverted) outcome: rows with
  `len < max(mean-3σ, 10)` are nulled, in-band rows survive. Add a level=4
  case covering the `> high` side.
- **Verify:** `pytest tests/test_clean.py -x` fails with exactly the two wrong
  comparisons; record which signs flip in the commit message.
- **Risks:** if it passes, current behaviour was intentional — halt and
  re-specify `LengthTrim` (plan §4 requires this).

### T1a — `steps.py` spec module
- **Goal:** step dataclasses exist, independent of any consumer.
- **Files:** `src/data/preprocess/steps.py` (new).
- **Changes:** frozen `kw_only` dataclasses per plan §2.1 (`CleanStep`,
  `LengthTrim`, `TokeniseStep`, `EmbedStep`, `DropNaStep`), `PipelineStep`
  union, a `tag` literal field per step for serialisation, and
  `step_to_dict` / `step_from_dict` built on `dataclasses.asdict` plus the tag
  discriminator. Define `StepContext` here too (runtime, embedder instance,
  partition index, logger).
- **Verify:** unit tests for `from_dict(step_to_dict(s)) == s` per step type,
  including `EmbedStep.kwargs` dict and `LengthTrim = None`;
  `pyright src/data/preprocess/steps.py` clean.
- **Risks:** none material; pure addition.

### T1b — CleanStep handler + `clean.py` rewrite
- **Goal:** clean operates from explicit flags; `Filter` dissolved.
- **Files:** `src/data/preprocess/clean.py`, `tests/test_clean.py`.
- **Changes:** replace `Filter` with deduped `EXCLUDE_QUALITY` /
  `EXCLUDE_LANG` constants; delete dead `tails`/`remove`; rewrite `main` as
  `run_clean(lf, step: CleanStep, ctx)`: lowercase flag, quality-substring
  nulling (flag-controlled, default on), `lang_policy` of `"mark"` (current)
  / `"drop"` / `"off"`, `trim` using T0-corrected semantics, terminal-period

- **Verify:** full `tests/test_clean.py` green; rest of suite green
  (`pipeline.py` untouched until T2).
- **Risks:** keep a temporary `main(...)` shim delegating to the handler until
  T2 removes it; dropping the shim is part of T2.

### T2 — Job rewiring + dispatcher
- **Goal:** `PreprocessJob.steps` drives execution; local runtime green.
- **Files:** `src/data/preprocess/pipeline.py`, `src/runtime/modal_runtime.py`,
  `src/data/preprocess/__init__.py`.
- **Changes:** swap the nine scattered fields for
  `steps: tuple[PipelineStep, ...]`; add `to_dict`/`from_dict` on the job.
  Move embed expression block and tokenise call out of
  `run_preprocess_pipeline` into `run_embed` / `run_tokenise` handlers in a
  `HANDLERS: dict[type, handler]` dispatch table alongside `run_clean` and a
  `DropNaStep` handler. Loop becomes
  `for step in job.steps: lf = HANDLERS[type(step)](lf, step, ctx)` with
  uniform row-delta logging in the dispatcher (info for clean/dropna, debug
  for embed/tokenise). Embedder instantiation moves into `StepContext`
  construction, derived by scanning `job.steps` for an `EmbedStep`. Fix
  `modal_runtime.py` debug log that reads `job.embedder_key`/`job.embed_cols`
  (both removed). Preserve dry-run semantics exactly (slice 500, print
  partition 0, break, no file written). Remove the clean shim.
- **Verify:** existing suite green (`test_pipeline_jobs.py`,
  `test_runtime_dispatch.py` updated in this commit); end-to-end run of
  `run_preprocess_pipeline` on a generated parquet fixture with
  `[CleanStep, DropNaStep]`.
- **Risks:** largest task; acceptable cut line if it balloons: defer uniform
  row-delta logging to T3. metadata.json currently writes raw
  `embedder_kwargs` — derive from the EmbedStep or note the format change.

## Plan-vs-code conflicts found

1. **Modal dispatch pickles jobs** (`fn.remote(job)`), it does not require
   JSON — plan §2.1's "must be JSON-serialisable" is wrong about the
   mechanism. Keep `to_dict`/`from_dict` anyway (metadata, tests); T3's
   round-trip test targets pickle.
2. **`modal_runtime.py` debug log breaks** when the nine job fields
   disappear; plan never mentions runtime/. Handled in T2.
3. **`Filter.tails` / `Filter.remove`** are dead lists; delete in T1b.
4. **`__init__.py` re-exports `clean_step`** bound to the old signature;
   shim in T1b, removal in T2.
5. **Dry-run** prints and breaks without writing; preserve verbatim.
6. **Row-delta logging costs one collect per step** in streaming mode;
   log embed/tokenise deltas at debug to avoid noise.
