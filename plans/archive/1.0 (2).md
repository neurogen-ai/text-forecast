## 1. Current state (read this first)

Typer CLI (`citef`, entry `src/main.py`) with sub-apps in `src/apps/`
(`train`, `eval`, `preprocess`, `describe`, `engineer`).

Configuration today is a "code-as-config" **singleton package** `src/config/`:

- `env.py` — module-level constants: `TRACKING_URI`, `EXPERIMENT`, `RAW_LOC`,
  `STAGED_LOC`, `ARTIFACT_LOC`.
- `model.py` — model class + pydantic config built at module level.
- `data.py` — train/test dataset configs + `DataLoaderConfig`s in `@dataclass`
  wrappers (`Train`, `Test`).
- `train.py` — `trainer`/`evaluator` classes + hyperparameters (`lr`, `epochs`,
  `loss_fn` as a registry string, lr-schedule params).
- `__init__.py` — eager imports + import-time `env.STAGED_LOC.exists()` assert.

Wiring is manual inside `src/apps/train.py` / `src/apps/eval.py`:

- Both `import config` at module top; construct model, datasets,
  `DLWrapper` (`src/data/dataloaders/DataLoader.py`), loss/optimizer via string
  registries (`builders/build_loss.py`, `build_optimizer.py`), LR scheduler via
  `builders/build_lr_scheduler.py` (LinearLR warmup → CosineAnnealingWarmRestarts
  → SequentialLR, params from `config.train`).
- `builders/build_tracker.py` hardcodes
  `_tracker = tracking.BinaryClassificationTracker` + long `StoreParams` tuples.
- Checkpoint save/load is inlined: train does `torch.save` to
  `ARTIFACT_LOC/EXPERIMENT/run_id/epoch-N.pt` + `mlflow.log_artifact`, and
  `client.download_artifacts` on resume; eval does the same download.
- `Trainer`/`Evaluator` ABCs (`src/training/trainers/base_trainer.py`,
  `src/eval/base_evaluator.py`) hold engine logic; app loop calls `.step(batch)`.
  `BaseTrainer.step` calls `mlflow.log_metric("train_loss-batch", ...)` directly.
- `MetricTracker` (`src/training/tracking/metric_tracker.py`) takes a
  `StoreParams` tuple + a loose `config` object; maintains GPU-side ring buffers
  (`Store`, `buffer_cursor`, `_flush_buffer`) flushed to CPU when full.
- Eval loops time windows via `copy.deepcopy(config.data.test.dataset)` +
  mutating `t_start`/`t_end`, and contains a **dead** `or True` short-circuit
  around downloading `config.py` from run artifacts.

Typing idioms to match: PEP 695 (`class Model[T_Config, T_In, T_Out](Protocol)`,
`GraphDataset[T_Config]`, `DLWrapper[T_Output]`); basedpyright **strict**.

## 3. Goal

A single **experiment module** per experiment at
`src/config/experiments/<name>.py` that:

1. Declares `experiment_name: str` (→ `mlflow.set_experiment(...)`).
2. **Directly instantiates** (no string registries) the full object graph inside a
   typed `build(runtime: RunContext) -> Experiment` entry point:
   Data Sources, Data Formaters, DataSets, Samplers, DataLoaders, Model,
   Strategy, Metric Tracker, Checkpoint processor, optimizer/scheduler **specs**.
3. Is selected with precedence: root CLI `--experiment/-e` → `config/config.toml`
   key `experiment` → hard crash listing available experiments.
4. Is fully checkable by basedpyright (strict) **while editing the file**:
   missing/positional args flagged via `Protocol`s, PEP 695 generics,
   `@dataclass(kw_only=True)`, pydantic models, and keyword-only (`*`) signatures.
5. Keeps a Lightning-compatible shape (`training_step` / `validation_step` /
   `configure_optimizers`, dict checkpoints, no direct mlflow calls in strategy).

**Non-goals:** `production/`, `preprocess`/`describe`/`engineer` internals
(→ `plans/1.1.md`), training math, dataset IPC caching internals, model
architectures, a real S3 implementation, any Lightning dependency.

## 5. Core contracts (write these FIRST)

Home protocols near their domain package; re-export from `src/config/protocols.py`.
PEP 695 style. **All constructors keyword-only.** NamedTuples remain the batch/
boundary types (H3).

```python
# --- DataSource (C1/C2: thin path resolver; dataset owns caching) ---
class DataSource(Protocol):
    @property
    def name(self) -> str: ...
    def resolve(self) -> Path: ...        # absolute path the Dataset reads/caches from

@dataclass(frozen=True, kw_only=True)
class LocalStagedSource:                  # src/data/sources/local.py
    root: Path
    name: str
    def resolve(self) -> Path: return self.root / self.name

# --- Formater (C3/C4: per-row value transforms only) ---
class Formater[T_In, T_Out](Protocol):
    def __call__(self, row: T_In) -> T_Out: ...

# --- Checkpointing (E2/E3/I3: full dict, no back-compat) ---
class Checkpoint(NamedTuple):
    model: dict[str, Tensor]
    optimizer: dict[str, Any] | None      # None when processor slimmed
    scheduler: dict[str, Any] | None
    epoch: int

class CheckpointRef(NamedTuple):          # identifies a remote/local checkpoint
    run_id: str
    epoch: int

class CheckpointProcessor(Protocol):
    def save(self, *, state: Checkpoint, run_id: str) -> str: ...   # returns path/URI
    def load(self, *, ref: CheckpointRef, map_location: torch.device) -> Checkpoint: ...

# MlflowCheckpointProcessor(artifact_loc: Path, include_optimizer: bool = True,
#                           include_scheduler: bool = True)   # slim flags (E2)
# also owns: download_experiment_file(run_id, dest) -> Path   # for eval (E5)

# --- Optimizer / scheduler specs (F4: IDE-checked in experiment file) ---
class OptimizerSpec(Protocol):
    def build(self, *, params: Iterable[Tensor]) -> Optimizer: ...

@dataclass(kw_only=True)
class AdamWSpec:
    lr: float
    weight_decay: float
    def build(self, *, params) -> torch.optim.AdamW: ...

class LRSchedulerSpec(Protocol):
    def build(self, *, optimizer: Optimizer) -> LRScheduler: ...

@dataclass(kw_only=True)
class WarmupCosineSpec:                    # mirrors build_lr_scheduler.py exactly:
    milestones: tuple[int, ...]            # LinearLR(start_factor→1.0, total_iters=m[0])
    warmup_start_factor: float             # + CosineAnnealingWarmRestarts(T_0=epochs-m[0],
    eta_min: float                         #   eta_min) + SequentialLR(milestones)
    epochs: int
    def build(self, *, optimizer) -> LRScheduler: ...

# --- Strategy (F1/F3/F4: one class, both steps, tracker logs everything) ---
class Strategy[T_Batch](Protocol):
    def configure_optimizers(self) -> tuple[Optimizer, LRScheduler]: ...
    def start_epoch(self, epoch: int) -> None: ...
    def move_to_device(self, batch: T_Batch) -> T_Batch: ...
    def training_step(self, batch: T_Batch) -> float: ...
    def validation_step(self, batch: T_Batch) -> float: ...

# --- Tracker (F5: dedicated classes, dict stores, CPU-copy per batch) ---
class MetricTracker:                       # rewritten base, src/training/tracking/
    store_names: ClassVar[tuple[str, ...]] # each subclass declares its own
    def __init__(self, *, device: torch.device, dtype: torch.dtype,
                 export: bool = False, export_loc: Path | None = None) -> None: ...
    # internally: self.stores: dict[str, list[Tensor]]
    # process_values(): NaN-check, value.detach().cpu(), append — NO GPU buffers,
    # NO StoreParams, NO Store/buffer_cursor/_flush_buffer machinery.

# --- Experiment (H3: generic, kw_only) ---
@dataclass(kw_only=True)
class Experiment[T_Batch]:
    experiment_name: str
    model: nn.Module
    strategy: Strategy[T_Batch]
    tracker: MetricTracker
    train_loader: DLWrapper[T_Batch]
    val_loader: DLWrapper[T_Batch]
    checkpoints: CheckpointProcessor
    epochs: int
    eval_interval: int
    checkpoint_interval: int
```

`RunContext` (`@dataclass(frozen=True, kw_only=True)`, `src/config/runtime.py`):
`device`, `dtype`, `mat_mul_precision`, `compile_mode: str`, `fullgraph: bool`,
`subsample: int | None`. Runtime = *how it runs*; it must NOT leak
experiment-relevant values (B1).

`Env` (`@dataclass(frozen=True, kw_only=True)`, `src/config/env.py`):
`tracking_uri: str`, `raw_loc: Path`, `staged_loc: Path`, `artifact_loc: Path`;
`load_env(overrides: Mapping[str, Any] | None = None) -> Env` reads
`<root>/config/config.toml` `[env]` via `tomllib`, applies CLI overrides,
validates `staged_loc.exists()` **at load time** (not import time).

`config/config.toml` schema:

